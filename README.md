# doubao-skills

一个总入口，按需调用各个子技能。包含 104 个本地技能目录，保留其脚本、参考资料、资源及已有许可文件。

## 使用

将目录作为 `doubao-skills` 放入客户端的技能目录，使用 `$doubao-skills` 指定任务。总入口按索引加载必要子技能，不把全部文档同时放进上下文。支持递归发现的客户端也可能单独显示各个子技能。

技能中的部分工具和服务依赖特定运行环境；打包不意味着它们在其他客户端已能直接运行。本集合未批量运行任何子技能脚本。

## 文件

- `SKILL.md`：总入口。
- `CATALOG.md` / `catalog.json`：子技能索引。
- `skills/`：保留目录结构的技能资料。
- `manifest.json`：子技能文件列表及 SHA-256。
